## How to read this file

1. **Authentication:** Protected endpoints require `Authorization: Bearer <Firebase_ID_token>`. Identity, role, organization scope, and ownership are always derived server-side from the verified token and database state — client-supplied owner, role, or organization claims do not grant access (`BR-03`, `FR-C-01`).
2. **Error envelopes (three route families exist in code):**
   - **CONV-1 routes** (`/api/auth/v1/*`, `/api/lesson-library/v1/*`, `/v1/upload-sessions*`, `/v1/lesson-occurrences*`, `/v1/notifications*`, `/v1/jobs/*`): Normalized by `error_envelope.py` into `{ "code", "message", "correlation_id", "field_errors"?, "retryable"?, "retry_after_seconds"?, "current_version"? }`. FastAPI `422` validation errors on CONV-1 paths are normalized to HTTP `400 INVALID_REQUEST`. `DEPENDENCY_UNAVAILABLE` maps to `PROVIDER_UNAVAILABLE`, `CONFLICT`/`INVALID_TRANSITION` map to `INVALID_STATE_TRANSITION`, and `*_NOT_FOUND` map to `RESOURCE_NOT_FOUND`.
   - **Parent Story routes** (`/v1/story-runs*`, `/v1/activities`, `/api/parent/v1/ai/story-runs/{run_id}/story-revisions`, `/api/parent/v1/ai/drawing-understandings`): Return `ParentStoryErrorEnvelopeV1`: `{ "code", "message", "correlation_id", "retryable", "retry_after_seconds"?, "field_errors"?: [{ "field", "code", "message" }], "current_version"? }`.
   - **Parent Profile routes** (`/v1/parent/profiles*`): Return `ParentErrorResponse` (`parent_error_payload`): `{ "code", "message", "correlation_id", "retryable", "request_id", "retry_after_seconds"?, "current_version"?, "field_errors"?: [{ "field", "code" }] }`.
3. **Conventions & Concurrency:**
   - **Idempotency:** Write endpoints requiring `Idempotency-Key` enforce 1–128 printable visible ASCII characters (`!`–`~`). Missing keys return `400 INVALID_REQUEST` (`field_errors` with `Idempotency-Key`); reusing a key with a different request payload returns `400 INVALID_IDEMPOTENCY_KEY` (or `INVALID_REQUEST` format depending on handler).
   - **Optimistic concurrency:** `/v1/parent/profiles` and `/v1/story-runs` pass `expected_revision` / `expected_*_revision` in the JSON body (not `If-Match`) and return `409 STALE_REVISION` with `current_version` (and `ETag` where applicable). Lesson Library & Push Endpoint mutations use `If-Match: "<revision>"` strong ETags (`400 INVALID_REQUEST` or `428 PRECONDITION_REQUIRED` depending on the endpoint).
4. **Demo-mode toggle note:** When `STORYRUN_LITE_MAIN_DEMO_ENABLED=1`, `story_run_lite_router` replaces `/v1/story-runs*` and `/v1/upload-sessions*` (`router_composition.py`). This reference documents the production/SRS routers active when the demo switch is off.
5. **Status legend:**
   - `MERGED` — Live in integration (`297f2849`).
   - `pending merge (Phase D, planned)` — Planned in `tmp/phase-v4/API_INVENTORY_V4_20261125.md`, not yet implemented.
