# ADR-0002: Human gates and original artwork are hard boundaries

- Status: PROPOSED
- Decision: Gate A and Gate B are mandatory workflow states. Original child media is immutable; generated learning media is a separate artifact.
- Reason: This is a product and safety invariant from the reference handbook and the user's request for review gates.
- Consequence: Every feature touching meaning, recommendations, or visuals needs approval and provenance evidence.
