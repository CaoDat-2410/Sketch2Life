# FEAT-069 product and API questions

The leader-review UI sequence is now represented for review. These items remain preview behavior or require an owner/SRS/API decision before they can be claimed as production workflows.

1. **Outdoor activity before video.** The Parent prototype now offers an optional activity tied to the selected lesson before its unavailable video request. This is the leader-requested review sequence, but SRS §5.1, FR-P-05 and FR-PL-16 place Parent activities after a playable video. Keep the screen labeled preview-only until the product owner resolves the conflict and updates the signed requirements.
2. **Context confirmation.** The separate context step is gone. The Parent script screen shows the minimal context snapshot and still requires adult confirmation before continuing, as FR-P-06 requires. Do not remove that confirmation without an approved requirement change.
3. **Child gender.** The Parent profile edit/detail views expose a gender choice only in the browser session. The current SRS/API profile model has no persisted gender field; this value is not sent to the API and will not survive a fresh session.
4. **Lesson mismatch choice.** Parent review has a user-triggered simulated mismatch modal with both leader-requested choices. There is no mounted image-analysis response/contract that can establish a real mismatch, so the UI must continue to identify this as a simulation and may not report an AI finding.
5. **Teacher dashboard from API.** Teacher, School Manager and Platform Admin dashboards remain fixtures. In this delivery branch, the web auth bridge `window.sketch2lifeAuth` and `GET /api/auth/v1/me` are absent; current user/organization context therefore cannot be derived safely. Do not hard-code a tenant or make shared writes with fixture identities.
6. **Live ASR, AI and run workflows.** Speech recognition, generated Teacher Show Slide content, complete occurrence/session persistence, image analysis, and the authenticated Parent story/video chain are not connected through the current UI route composition. Audio text remains adult-entered, slide/guide art is static, and the video request stays unavailable.
7. **APK runtime on the supplied emulator.** Parent Android embeds the `parent-ui` Vite bundle and the rebuilt debug APK packages successfully. The supplied emulator's Android Package Manager stalled/failed during installation attempts; the APK has not been runtime-verified on that emulator. The web phone preview is not proof of APK startup.

The approved Rev2 scope provides review prototypes while FEAT-063 SRS v2.5-draft remains the canonical working source pending formal owner sign-off. No API, schema, auth, backend or SRS changes were made.
