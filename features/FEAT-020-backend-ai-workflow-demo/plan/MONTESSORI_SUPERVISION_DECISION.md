# FEAT-020 Montessori Supervision and Duration Decision

## M-020-03 — Adult supervision and catalog duration

**Status:** confirmed by owner; grouped plan milestone
**Date:** 2026-09-12

Every demo activity requires an adult/guide supervision record. The activity duration is taken from the selected activity catalog record rather than invented by the workflow or changed only to make the demo fit a fixed timer.

The handoff must expose supervision requirement, duration, safety notes, and the selected activity/version. A future UI may render these fields, but FEAT-020 only emits the backend contract.
