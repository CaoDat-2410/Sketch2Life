# FE_UI_Project screenshot pack

Captured from the UI branch at commit c384dcc6705b54005eea5e3ce21ecccf349498d5.

This set contains 37 screenshots from every route screen in the four Parent, Teacher, School Manager, and Platform Admin portals added or rewritten by FE_UI_Project. The Parent set includes its splash, three onboarding steps, authentication, and the child-profile section.

The pages were rendered in local preview with synthetic demo data using Google Chrome headless 157.0.8103.38. Parent uses a 430×932 viewport; Teacher, School Manager, and Platform Admin use 1440×1000. Screenshots show one viewport per route. No backend credentials, provider calls, or real child data were used.
