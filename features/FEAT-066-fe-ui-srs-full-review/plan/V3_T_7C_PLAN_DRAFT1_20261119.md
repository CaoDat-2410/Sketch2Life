## 3. Route contract

`POST` as D1. Headers `Idempotency-Key` (required), `If-Match` (required, strong `"N"`, `_strong_revision`). Body `{display_name, age_months, consent_id?}`, `extra=forbid`, `child_id`, `purpose_ref`, `data_origin`, `class_id` rejected. 201 body `{"contract":"Be1ManagedProfileV1","child_id","class_id","enrollment_id","display_name","age_months","data_origin","class_revision"}` + `ETag`. Errors: 400 `INVALID_REQUEST`, 400 `INVALID_IDEMPOTENCY_KEY`, 403 `ACTION_NOT_ALLOWED` (School Manager: in scope, role refused, no child data to the Manager), 404 uniform (unknown class, other organization, unassigned Teacher, org-wide Teacher row, Parent, Platform Admin), 409 `STALE_REVISION`, `INVALID_STATE_TRANSITION`, `SYNTHETIC_PROFILE_CREATION_UNAVAILABLE`, `CONSENT_NOT_EFFECTIVE`, 422 age rule (`validate_age_months`). No new error code (`error_envelope.py` untouched). Catalog: no new operation; the row's `request_inputs` (`openapi_contract.py:3579-3603`) and examples (`openapi_contract_amendments.py:289, 303`) change.

**Order:** class by (org, id) any state, missing -> 404 (kept first: `test_missing_or_wrong_class_scope_uses_generic_denial`); `_require_m2_assignment(roles={"teacher"}, class_id)` and the class-scoped `teacher` row check; key; `If-Match`; `FOR UPDATE` on the class (`class_lock_any_state`); receipt replay (stored result, `db.rollback()`); stale revision; class active; mode matrix; validation; real branch or synthetic ids; insert profile and enrollment (`state active`) in one flush; `audit("profile.enroll")` and `event("be1.profile.enrolled.v1")` as today; receipt; `commit`. Fingerprint: sha256 of `{display_name, age_months, consent_id, if_match}`. Receipt-key race: `IntegrityError` -> rollback and replay, as `create_class`.
Concurrency: the class lock serializes creates and state or move commands of the class; two creates with the same revision both succeed (create does not bump); same key twice -> one profile.
