| D1 | **One route, two bodies; the Parent path is not edited.** Mechanism: a small `APIRoute` subclass (`RoleDispatchedCreateRoute`, new module `interfaces/http/routers/story_run_create_dispatch.py`) registered for the one operation `POST /v1/story-runs` only. It wraps the existing Parent endpoint exactly as it is today (same function, same signature, same `response_model`, so the generated OpenAPI of the Parent operation does not change) and holds a second, hidden `APIRoute` (`include_in_schema=False`) for the Teacher endpoint. The wrapper reads the raw body once (Starlette caches it) and decides by SHAPE: a JSON object with at least one Teacher key (`profile_ref`, `occurrence_id`, `plan`, `activity_id`, `selection_id`, `selection_sha256`, and the multi-child spellings `profile_refs`, `child_ids`, `children`, `profiles`) goes to the Teacher endpoint; everything else (a Parent body, an empty body, invalid JSON, an array) goes to the Parent handler untouched. ## 8. Concurrency

Two creates racing for one selection: the `FOR UPDATE` plus compare-and-set let one consume it; the other gets 409 `INVALID_STATE_TRANSITION`. A plan confirm racing a create: the occurrence lock orders them (a create after the confirm sees the new plan and refuses the old pin with 409 `STALE_REVISION`). A suspend racing a create: the class lock orders them. An `IntegrityError` on a unique index is mapped by constraint name, never 500.
