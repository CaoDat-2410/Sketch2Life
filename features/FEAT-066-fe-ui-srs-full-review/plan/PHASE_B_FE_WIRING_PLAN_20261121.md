## 2. Error copy (SRS §9.8 l.860-873 and §21.6 l.1715-1735)

The backend sends the CONV-1 envelope with the Vietnamese messages of `error_envelope.py` (the same strings as `shared/api/errorEnvelope.ts`); the screens add the recovery step that §21.6 names:

| Code | Screen text (server message + recovery) | Basis |
|---|---|---|
| `STALE_REVISION` | server message, then "Đã tải lại dữ liệu mới nhất; hãy kiểm tra rồi xác nhận lại." and a reload | l.1699, l.1724 |
| `INVALID_IDEMPOTENCY_KEY` | server message; the key is dropped so the next press is a new command | l.1697 |
| `INVALID_STATE_TRANSITION` | "Lớp không còn ở trạng thái cho phép thao tác này (lớp tạm ngưng chỉ đọc, mọi dữ liệu vẫn được giữ)." and a reload | l.593, l.862-866 |
| `RESOURCE_NOT_FOUND` / any 404 | one text: "Không tìm thấy nội dung hoặc bạn không có quyền truy cập. Hãy làm mới danh sách." and a list reload | l.865, l.1720 |
| `ACTION_NOT_ALLOWED` / 403 | "Tài khoản không được phép thực hiện thao tác này." (no policy detail), no retry | l.864, l.1721 |
| `RATE_LIMITED` | "Bạn đã gửi quá nhiều yêu cầu. Vui lòng thử lại sau N giây." from `Retry-After`; no automatic retry | l.872, l.1735 |
| `SYNTHETIC_PROFILE_CREATION_UNAVAILABLE` | "Môi trường này chưa cho phép tạo hồ sơ thử nghiệm (synthetic)." | T-7c evidence; no SRS literal |
| `INVALID_REQUEST` | server message (field errors stay field path + code only) | l.862 |

No SRS sentence exists for the confirm dialogs; their copy reuses l.593 ("Lớp tạm ngưng chỉ đọc, mọi dữ liệu vẫn được giữ") and FR-T-05 l.544 ("khi chuyển lớp thì đóng và lưu enrollment trước đó").

## 5. Open questions (recorded, not decided here)

- O-1: no restore/unarchive or reactivate route (SRS l.1896 ties reactivation to capacity); the UI offers none.
- O-2: A10 returns `effective: false` for every row (pre-existing, also at `bb73e958`); the Teacher roster joins A09 rows to effective consents, so a Teacher sees no names until the consent model (X-19) sets `effective`. The web keeps the fail-closed join.
- O-3: Synthetic profiles have no consent purpose, so A09 answers 409 `CONSENT_NOT_EFFECTIVE` once one exists in a class; the create form is useful for the synthetic pilot only, and the roster then shows the 409 text.
- O-4: The occurrence page keeps `state=active`; whether a Teacher should see a suspended class there read-only is a later UI decision.
