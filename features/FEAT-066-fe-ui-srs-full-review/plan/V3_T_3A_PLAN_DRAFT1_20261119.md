## 2. Decisions (SRS-cited)

- **T3A-D1 Path and family (l.1652, l.798, TD-01/TD-05).** New router `interfaces/http/routers/lesson_occurrences.py`, prefix `/v1/lesson-occurrences`, tag `Lesson Occurrences`; mounted in `mount_all_routers` unconditionally (no flag collision). `/v1/lesson-occurrences` joins `CONV1_PREFIXES` (R10). T-3b..T-3d add routes to the same router.
- **T3A-D2 Actor and scope (l.1652 "Teacher được phân công", l.864-865, C-D4, CV-5).** Body carries only `class_id`, `title`, `scheduled_date`, `lesson_version_ref`; `extra=forbid` (any organization, owner or teacher field is 400 `UNKNOWN_FIELD`, l.1637). Organization is derived from `be1_classrooms.class_id`. Flow: (1) class unknown, or the caller has no active teacher-family row in the class's organization (or inactive/non-Teacher account): uniform 404 `RESOURCE_NOT_FOUND` (via `require_assignment(..., roles={"teacher","guide","observer"})`, wrapped like `_require_m2_assignment`); (2) in scope but no active `teacher` row covering this class: **409 `TEACHER_ASSIGNMENT_REQUIRED`** (the plan's "in-scope only" rule; only after step 1 passed, so a stranger never learns that a class exists); (3) a `guide`/`observer` row only: 403 `ACTION_NOT_ALLOWED` (in-scope role refusal); (4) class `state <> 'active'`: 409 `INVALID_STATE_TRANSITION` (UC-04 "occurrence cho phép ghi"). Capacity is X-13 and not checked (no `CLASS_CAPACITY_REACHED`; l.1652 says "xác minh sức chứa/phân công" but Billing is deferred, R3).
- **T3A-D3 Occurrence scope for existing ids (reads and, in T-3b..T-3d, writes).** Visible iff the caller is an active teacher-family account with a row covering the occurrence's class (current assignment). Out of scope, unknown id, other organization, assignment revoked: uniform 404. Writes need the `teacher` role and `responsible_teacher_ref == caller account` else 403 `ACTION_NOT_ALLOWED`. A Teacher replaced on the class loses access; occurrence transfer belongs to UC-12 / T-6b (open question OQ-2). School Managers and Platform Admins get 404 (no SRS route for them; they never see plan or document content, R12).
- **T3A-D4 Opaque refs (REG l.352).** `responsible_teacher_ref` and `created_by` store `be1_adult_identities.account_id` (never the IdP subject); `organization_ref`/`class_ref` are strings with **no cross-owner FK** (REG: "opaque"); integrity is checked in the service in the same transaction (class row read `FOR SHARE`).
- **T3A-D5 Keys and receipts (l.1697, C-D5, C-D6).** `POST` requires `Idempotency-Key` (1-128 visible ASCII; missing/malformed 400 `INVALID_REQUEST`); receipts in `be1_command_receipts` (`operation_scope="POST /v1/lesson-occurrences"`, `organization_id` set, fingerprint over the canonical body); same key and payload replays the stored 201 after re-authorising the caller; another payload: 400 `INVALID_IDEMPOTENCY_KEY`. A different key with an identical body creates a second occurrence (the SRS gives no uniqueness on label or date).
- **T3A-D6 Optional lesson pin (l.547, REG l.352).** Body `lesson_version_ref: {lesson_id, version_id, version_no, content_hash}`, all four or none. The service resolves the version in `lesson.library_versions` joined to its item: same organization as the class, visible to the caller by the `get_lesson` rule (§1 last bullet), and `version_no` and `structured_content_hash` equal the request (a mismatch is 409 `STALE_REVISION`; an unknown or invisible version is 404); never `latest`. Stored exact; never retargeted (§31.2, §31.8.2). Whether a pinned version must be `APPROVED` is not in the SRS (OQ-3, default: any visible version).
- **T3A-D7 Revisions and ETags (C-D7, l.1699).** `lesson.occurrences.revision` starts at 1, +1 on every state or approved-plan change. Reads return strong `ETag: "<revision>"`; `If-None-Match` gives 304 after authorisation. Creates of the next document/plan revision carry a body `expected_head_revision_no` (T-3c, T-3d); the occurrence itself has no PATCH in v3 (the SRS has none).
- **T3A-D8 Upload target resolver.** T-2a plans a resolver registry for purpose `OCCURRENCE_DOCUMENT` (`target_ref` = occurrence id; create answers 404 while none is registered). T-3a registers `OccurrenceUploadTargetResolver` (read-only, T3A-D3 scope, role `teacher`, responsible teacher, occurrence writable) so T-3b has its carrier at once. The registration hook name comes from T-2a's final code (re-verify; if T-2a lands without a hook, T-3a adds the smallest one in `router_composition.py`, recorded as a deviation).
- **T3A-D9 List route boundary.** `GET /v1/lesson-occurrences?class_id=...` is an occurrence-state list (l.798 group), **not** the X-17 run/occurrence history list: `class_id` is required, no run or job data. If the owner rules any occurrence list is X-17 (OQ-1), drop it; the single GET stays.

| Route | Actor | Request | Success | Errors |

## 4. DDL-A (migration `20261119_oc_0001_lesson_occurrence_plan.py`, approve by name before first migration)

`revision "20261119_oc_0001"` (16 chars), `down_revision` = the single `lesson_library` head at implementation start (**expected `20261119_uf_0001`** from T-2a; `20261119_ar_0002` if T-2a is absent; run `alembic heads` first), `branch_labels None`, `depends_on None`; heads stay 14/10, graph 33 -> 34 (35 after T-2a). Create-only (no existing table altered). Registers amend REG l.352-356 as noted. All ids `VARCHAR(36)`, times `timestamptz`, `ON DELETE RESTRICT`. Names below are CHECK/UNIQUE names.

1. **`lesson.occurrences`**: `occurrence_id` PK; `organization_ref VARCHAR(128)`, `class_ref VARCHAR(128)`, `responsible_teacher_ref`, `created_by` (NOT NULL, no FK); `title VARCHAR(200)` (`ck_occ_title` non-blank); `scheduled_date DATE NULL`; `state VARCHAR(16) DEFAULT 'PLANNING'` (`ck_occ_state`: PLANNING, PLAN_APPROVED, ARCHIVED reserved); `revision INTEGER DEFAULT 1` (`>0`); `approved_plan_revision_id NULL` (FK to `lesson.plan_revisions`, `DEFERRABLE INITIALLY DEFERRED`, added after that table; `ck_occ_plan_state`: `(state='PLAN_APPROVED') = (approved_plan_revision_id IS NOT NULL)` for non-archived rows); pin columns `source_lesson_id`, `source_lesson_version_id`, `source_lesson_version_no INTEGER`, `source_lesson_version_hash VARCHAR(64)` all-or-none (`ck_occ_pin`) with `length(hash)=64`; `sample_slot_state VARCHAR(16) DEFAULT 'AVAILABLE'` (`AVAILABLE|CLAIMED`; **values are the plan's proposal**, REG names the column only), `successful_sample_run_ref VARCHAR(128) NULL`, `sample_claimed_at NULL` (`ck_occ_sample`: CLAIMED iff claimed_at set), `class_projection_confirmed_by_ref NULL`, `class_projection_confirmed_at NULL` (columns kept so DDL-B2 adds nothing here; unused in v3); `created_at`, `updated_at`. Indexes `ix_occ_class_created (class_ref, created_at DESC, occurrence_id DESC)`, `ix_occ_teacher (responsible_teacher_ref, created_at DESC)`.
   Trigger `lesson.protect_occurrence` (BEFORE UPDATE OR DELETE): DELETE forbidden; `occurrence_id, organization_ref, class_ref, created_by, created_at` and the four pin columns immutable (`responsible_teacher_ref` stays mutable for T-6b).
2. **`lesson.source_documents`** (T-3b): `source_document_id` PK; `occurrence_id` FK; `asset_ref VARCHAR(256)`, `asset_version INTEGER DEFAULT 1` (UNIQUE pair `uq_srcdoc_asset`); `upload_session_ref VARCHAR(36) UNIQUE`; `extraction_job_ref VARCHAR(128)` (opaque `ai_jobs.job` id); `safe_file_name VARCHAR(255)`; `file_extension` in `.pdf|.docx|.pptx`; `page_or_slide_count INTEGER NULL` (1..100); `document_state` (`EXTRACTED|DELETED`) and `deleted_at` (`ck`: DELETED iff deleted_at set); `uploaded_by`, `uploaded_at`. Media type, size and SHA-256 stay in Core Asset (REG). Trigger `protect_source_document`: everything immutable except `document_state`, `deleted_at`; DELETE forbidden. Index `(occurrence_id, uploaded_at)`.
3. **`lesson.document_revisions`** (T-3b, T-3c): `document_revision_id` PK; `source_document_id` FK; `revision_no INTEGER` (`>0`, `UNIQUE(source_document_id, revision_no)`); `origin` (`EXTRACTION|TEACHER_EDIT`, plan addition for provenance, FR-T-07); `base_revision_no INTEGER NULL` (`ck`: EXTRACTION iff `revision_no=1` and base NULL; edit iff base set and `< revision_no`); `extracted_text TEXT` (`ck`: `octet_length BETWEEN 1 AND 2097152`, the parser bound); `extracted_text_hash VARCHAR(64)` (SHA-256 of the UTF-8 bytes); `parser_name`, `parser_version` (NOT NULL iff EXTRACTION); `extraction_warnings JSONB` and `page_coverage JSONB` (arrays); `review_state` (`NEEDS_REVIEW|CONFIRMED`), `reviewed_by`, `reviewed_at` (CONFIRMED iff both set); `created_by`, `created_at`. Trigger `protect_document_revision`: DELETE forbidden; UPDATE allowed only for the one-way `NEEDS_REVIEW -> CONFIRMED` stamp (sets `reviewed_by/at`), every other column identical (T-3d stamps it at plan confirm, T3D-D5).
4. **`lesson.plan_revisions`** (T-3d): `plan_revision_id` PK; `occurrence_id` FK; `revision_no` (`UNIQUE(occurrence_id, revision_no)`); `source_document_revision_id NULL` FK to `document_revisions` (optional per REG; a BEFORE INSERT trigger checks it belongs to the same occurrence); `objectives JSONB` (array of 1-12 strings; REG says singular `objective`, amended, because l.1659 says "objectives" and the parser yields a list); `teacher_direction TEXT` (1-2000 chars), `safety_notes TEXT NULL` (<= 2000); `state` (`DRAFT|APPROVED|SUPERSEDED`); `content_hash VARCHAR(64)`; the four optional pin columns (equal to the occurrence's pin when the occurrence has one, service rule); `created_by`, `created_at`, `approved_by`, `approved_at`, `superseded_at` (plan addition, §31.8.2). `ck`: state not DRAFT implies approved_by/at set; SUPERSEDED implies superseded_at. **Partial unique index `uq_plan_one_approved (occurrence_id) WHERE state='APPROVED'`** (l.775: at most one approved plan). Trigger `protect_plan_revision`: DELETE forbidden; content columns immutable; allowed transitions only `DRAFT->APPROVED` (needs approved_by/at; **fails `LESSON_PLAN_CHECKLIST_REQUIRED` while any `CUSTOM` activity lacks `confirmed_at`**, the DB backstop for FR-T-09 l.548) and `APPROVED->SUPERSEDED`.
5. **`lesson.plan_activities`** (T-3d): `plan_activity_id` PK; `plan_revision_id` FK; `activity_order` (`UNIQUE(plan_revision_id, activity_order)`, `>0`); `activity_kind` (`CATALOG|LESSON|CUSTOM`; v3 accepts `LESSON` and `CUSTOM`, CATALOG waits for TD-16); `catalog_activity_ref VARCHAR(256) NULL` (for `LESSON`: the library `version_activities.activity_id`), `activity_version INTEGER NULL`; `custom_title VARCHAR(200)`, `custom_description TEXT` (<= 4000) required for CUSTOM; `activity_snapshot JSONB` (exact copy pinned at create, plan addition: REG has only the hash); `activity_snapshot_hash VARCHAR(64)`; `safety_checklist_version VARCHAR(32) NULL`, `checklist_result JSONB NULL`, `confirmed_by NULL`, `confirmed_at NULL`. Trigger `protect_plan_activity`: DELETE forbidden; INSERT only while the parent plan is DRAFT; UPDATE only sets the four checklist columns from NULL, only while the plan is DRAFT.

**Downgrade:** raises `RuntimeError` while any of the five tables holds a row (data is not silently dropped; FR-C-08 style guard), else drops triggers, functions (`lesson.protect_*`), indexes, then tables in reverse FK order (after dropping the deferred FK from `occurrences`). Verify: `alembic upgrade heads` on a fresh database, an upgrade/downgrade/upgrade round trip, and the same on a database that went through `20261103_story_upload_compat`.
