## 5. State machine (`domain/story_video/model.py`, pure)

Generation: `ADMISSION_PENDING` to `ACCEPTED|ADMISSION_REJECTED`; `ACCEPTED` to `QUEUED` to `GENERATING` to `TECHNICAL_VALIDATING` to `SAFETY_VALIDATING` to `READY|SAFETY_BLOCKED`; any in-flight state (and an intent resolved after cancel) to `FAILED`; `READY` to `REJECTED_BY_ADULT` (T-1b) or `SUPERSEDED`. Run: `SCRIPT_REVIEW` to `VIDEO_ADMISSION_PENDING` to `VIDEO_QUEUED` or back to `SCRIPT_REVIEW`, then D11. One constant maps generation state to run state and drives service and tests.
