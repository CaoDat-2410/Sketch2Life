## 5. Authorization and no-child-data rules

1. **Who:** an active identity with role `parent` or `teacher` and a matching issuer (D1). A Teacher acts on a run only through the occurrence-pin rule on the CURRENT assignment, evaluated at every call (nothing cached, no token or session carries it); `created_by_actor_ref` never grants (l.553).
2. **Wrong actor:** one uniform 404 `RESOURCE_NOT_FOUND`, same bytes, no write, for: no identity, inactive, issuer mismatch, Manager, Platform Admin, Parent on a Teacher run, Teacher on a Parent run, unassigned Teacher, org-wide Teacher, guide, observer, foreign-organization Teacher, revoked Teacher, the creating Teacher after the occurrence moved to another Teacher, a fixture run without a pin, an unknown id. No timing difference is claimed.
3. **Teacher sees Teacher-typed snapshots only:** the run view is `TeacherStoryRunEnvelopeV1` (T-4b2): a string profile ref, the occurrence, plan and activity pins, Teacher-typed `context_snapshot` and `lesson_pin_snapshot` (no name, no media, no seed, no draw index). The step responses add nothing child-related.
4. **No storage URL, key, bucket or signed link** in any body, header, log line or audit row: the asset ref is the opaque upload handle, the video is reached only through the playback route, `Cache-Control: private, no-store` stays on the transcript and the stream. No child name, seed or draw index is written to any Story table by a Teacher step: the audit rows of D13 carry the run id and a safe code only; the worker input carries the confirmed subject and visible features of the DRAWING (the same fields a Parent run sends), never the profile name.
5. **Lock order** is the T-4a1 order for every step (run `FOR UPDATE`, assignment and class `FOR SHARE`); no step locks the occurrence (the access rule reads it plainly), so there is no cycle with T-4b2 (occurrence, class, selection) or with T-5a (occurrence `FOR UPDATE`, class, run `FOR SHARE`: the run lock waits behind the step's, the step never waits behind the occurrence lock). A class suspension (`FOR UPDATE` on the class row only) waits for an in-flight step.
6. **Provider and quota hard scope:** the ports used are the existing fixture and local adapters; nothing is called in the shipped composition (the analyzer, transcriber, story generator and video ports are `None` or local-only there); no `billing.*`, `ai_policy.*` or capacity table is read or written by the new code (a test counts rows).
