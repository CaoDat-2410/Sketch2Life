## 3. Response shape (additive; three fields kept)

```
200 {"role","state","role_revision",
     "scope": {
       "organizations": [{"organization_id","display_name","roles":["teacher"|"school_admin"|"guide"|"observer"]}],
       "classes":       [{"organization_id","class_id","display_name","role","state"}],
       "accounts":      {"account_id":"<own>","managed":"NONE"|"PLATFORM"},
       "permissions":   [],
       "truncated":     false}}
```
- Only active assignments in active organizations. A `school_admin` row with null `class_id` is org-wide: it appears in `organizations[].roles`, not in `classes` (no class enumeration).
- Parent: empty `organizations`/`classes`; `accounts.managed` `NONE`. Platform Admin: empty org/class lists, `managed` `PLATFORM`. `permissions` is always `[]` until TD-11 (Content Admin store).
- Caps 100 organizations and 500 classes, stable order (id); `truncated` true when cut. Header `Cache-Control: private, no-store`.
- 403 refusal unchanged (code, no UID, identical for the four causes). 401/503 come from `get_verified_adult`/`get_db`.
- No new route, no DDL, no migration.
