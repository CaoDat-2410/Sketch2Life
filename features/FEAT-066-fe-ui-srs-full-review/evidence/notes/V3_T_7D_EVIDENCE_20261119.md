### Handler order (`move_profile`)

1. Source class by id in any state (404 uniform when missing). 2. Teacher row of the source class: `_require_m2_assignment(roles={"teacher"})` plus the class-scoped row check (School Manager 403, guide and observer rows 403, org-wide row, other class, other organization, Parent, Platform Admin 404). 3. `Idempotency-Key` (1-128, `parse_idempotency_key`), strong `If-Match` (source class revision), same class as target -> 400 `INVALID_REQUEST` (`target_class_id`, `INVALID_FORMAT`). 4. Target class in the SAME organization and an active class-scoped `teacher` row of the caller on it, else the same uniform 404. 5. Both class rows `FOR UPDATE` in ascending `class_id` order (A->B and B->A cannot deadlock). 6. Receipt `(principal, "POST /classes/{class_id}/profiles/{child_id}/move", key)`: same fingerprint -> stored references (body rebuilt so the replay is byte-identical, JSONB reorders keys), other fingerprint -> 400 `INVALID_IDEMPOTENCY_KEY`. 7. Stale source then stale target -> 409 `STALE_REVISION` (`current_version` and `ETag` of the failing class). 8. Both classes `active` else 409 `INVALID_STATE_TRANSITION`. 9. Profile row `FOR UPDATE` (`organization, child_id, class_id == source, state active`, else 404 `PROFILE_NOT_FOUND`, `RESOURCE_NOT_FOUND` on the wire), active enrollment row `FOR UPDATE` in the source (none -> 409, not auto-enrolled), session guard (409). 10. One transaction: source enrollment `withdrawn` (flush), new `active` enrollment in the target (`uuid4`, `created_by` the caller), `profile.class_id = target` (ORM attribute assignment, so the profile age invariant pin does not trip), both class revisions +1, `audit("profile.move")`, outbox event `be1.profile.moved.v1` `{child_id, from_class_id, to_class_id}`, receipt (references only), one commit. A commit `IntegrityError` rolls back and replays the winner (same key) or answers 409 `RESOURCE_CONFLICT`.

200 body: `{"contract": "Be1ProfileMoveV1", "child_id", "from_class_id", "to_class_id", "enrollment_id", "from_class_revision", "to_class_revision"}`. No `ETag` header (two resources). No name, age, consent state or count anywhere.
