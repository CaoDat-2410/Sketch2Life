## 1. What changed

Source: `backend/src/sketch2life/interfaces/http/routers/be1_registry.py`, two guard edits, no new route, no DDL, no contract or OpenAPI change.

- `GET /api/be1/v1/organizations/{organization_id}/classes/{class_id}/profiles` (`list_profiles`): `require_assignment(...)` now passes `roles=frozenset({"teacher", "guide", "observer"})`. A `school_manager` account keeps only `school_admin` assignment rows, so the guard gives it 403 `ACTION_NOT_ALLOWED`. A `teacher` account already keeps only these three roles, so Teacher behaviour is unchanged.
- `GET /api/be1/v1/organizations/{organization_id}/sessions/{session_id}/pilot-profiles` (`list_pilot_profiles`): `roles={"teacher", "school_admin"}` became `roles={"teacher"}`. The Manager now gets 403 before the pilot-disabled 409 and the lobby 409, in every state. A Teacher account with a `guide` or `observer` row already got 403 and still does.
- Out-of-scope callers (unknown organization, class outside the assignment, other account roles, inactive identity) still get the uniform 404 `RESOURCE_NOT_FOUND`: the 404 check runs before the role check inside `require_assignment`.
