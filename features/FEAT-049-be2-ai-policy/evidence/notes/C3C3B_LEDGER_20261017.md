## Implemented

ResourceLedgerStore/transaction port and SQL adapter. One org/feature scope UPDATE
lock serializes resource changes across all budget windows/definitions. Per-bucket
held/spent and global occupied slots load together under that lock. Reservation
identity binds original request/attempt/terms; unique org/request-digest/attempt
prevents another id/window allocating the same attempt again. Reserve/settle
delegate immutable domain transitions; exact replay creates no event/delta.

Same connection/transaction updates counters/reservation, scoped receipt and
resource_event audit/outbox intent. Any command exception or write conflict rolls
back the candidate through engine.begin; no blind retry. SQL exceptions translated
to safe resource-write-conflict/storage-unavailable codes, not raw driver details.
No policy/owner lock or network provider work is acquired from inside ledger UoW.

Own five-table metadata and forward ap_0003, additive Alembic registration. Composite
org/feature/reservation FKs for receipts/events; terminal reservation/original terms,
bucket identity, receipts and audit payload protected from rewrite. Delivery marker
alone remains mutable. Stored domain payload decoder rechecks invariants and
fixture/runtime evidence distinction; JSON payload is not independent authority.
