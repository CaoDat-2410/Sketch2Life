# FEAT-024 decisions

## D-024-01 — Version continuity semantics instead of redefining V1

Decision: keep the existing V1 projection readable and introduce explicit V2
continuity fields. `video_continuity` in V1 is treated as a legacy planned
projection; actual rendered-video continuity is nullable until a renderer and
post-generation evaluator exist.

Reason: changing the meaning of a required V1 integer would create silent
contract debt for existing consumers.

## D-024-02 — Related expansion is allowed but must be labeled

Decision: a lifecycle activity can remain selectable for an observed butterfly,
but it must be `RELATED_EXPANSION`, receive a bounded relevance penalty, and
carry a bridge cue that introduces the unobserved lifecycle stages.

Reason: educational value and scene grounding are both preserved without
pretending that eggs, caterpillar or chrysalis were in the child's drawing.

## D-024-03 — Mechanical repair only at the VLM boundary

Decision: normalize safe structural mistakes, but never invent observations,
relations, concepts, transcript text or recommendations. If normalization
leaves no valid observation, return a typed failure.

Reason: case 02 must become robust without turning a real-AI demo into a hidden
fixture or hallucination fallback.

## D-024-04 — Repair is opt-in at the real CLI boundary

Decision: keep the adapter default strict for mapping studies and contract
tests; enable the bounded structural repair flag only in the real workflow CLI.

Reason: real model drift needs a recovery path, while the default port must
continue to reveal schema regressions instead of silently normalizing every
caller.

## D-024-05 — VLM-only is a degraded but valid multimodal route

Decision: a typed ASR failure does not block catalog selection when VLM returns
validated visual observations. The output carries the ASR failure metadata,
uses `VLM_ONLY` scene resolution, and marks story grounding accordingly.

Reason: audio is an independent modality; hiding usable visual evidence behind
an aggregate `AI_FAILED` result would make case 02 unnecessarily brittle.

## D-024-06 — Bridge content is authored catalog metadata

Decision: setup, focus cues, handoff wording and off-screen instructions are
variant metadata with explicit `expansion_bridge_required`, not generated by a
runtime fallback sentence.

Reason: age and activity safety instructions must be reviewable, reproducible
and stable when the UI is added later.
