## Implementation and safety

strict content DTOs and all eight learning_content actions. Mandatory injected
resolver supplies verified principal/org; no client identity/header role bypass.
Application current guard still verifies action permissions and scope at commit.
The default application is unchanged, so the candidate route is not exposed by
production composition. No second delivery gateway or direct foreign DB access.

Admission limit is explicitly injected by composition, not invented as production
policy. Streaming counts bytes; invalid media type, duplicate JSON fields, NaN,
invalid UTF-8/JSON/strict models are rejected. Strong quoted positive record
If-Match is separate from target version/review revision. Shared error envelope
uses safe codes/fixed message/correlation, not body or raw adapter exception.
Unknown domain codes are hidden behind dependency unavailable; unexpected
exceptions produce generic 500. Responses are no-store and include current ETag.
Complete inline finite DTO OpenAPI has no unresolved $ref/discriminator mappings.
