# Official technology logo provenance

These five marks identify the technologies named in the SRS on System Architecture v2. They remain the property of their respective owners and are not relicensed under the project's code license. Their placement does not imply endorsement, partnership, implementation completion, or an infrastructure decision. Source URLs, exact byte lengths and SHA-256 hashes are in `manifest.json`.

- **FastAPI:** the original square teal mark comes from the official `fastapi/fastapi-vscode` repository at pinned commit `39e53827997a41c288b323f1881752c590940d27`. The [FastAPI about page](https://fastapi.tiangolo.com/about/) identifies the trademark owner as @tiangolo. The repository's code license does not remove trademark rights.
- **Firebase:** the original full-color primary logomark comes from the asset ZIP linked by the [official brand guidelines](https://firebase.google.com/brand-guidelines). Firebase is a Google LLC brand. Its guidelines require the current artwork, unchanged colors and proportions, adequate separation, legibility and no endorsement implication. The diagram uses a 48px image box and a separate Authentication label; it introduces no other Firebase product.
- **React Native:** the original cyan header mark comes directly from `reactnative.dev/img/header_logo.svg`, also referenced by the [official Image documentation](https://reactnative.dev/docs/image). React and React Native branding belong to Meta Platforms, Inc.; the logo serves as a technology identifier for the confirmed Android client.
- **PostgreSQL:** the three-color Slonik elephant comes from the [PostgreSQL project's logo catalog](https://wiki.postgresql.org/wiki/Logo) and remains subject to its [trademark policy](https://www.postgresql.org/about/policies/trademarks/). PostgreSQL is a trademark of the PostgreSQL Community Association of Canada. The database remains a candidate in the diagram.
- **Redis®:** the current original red wordmark is preserved from the [official Redis homepage](https://redis.io/), rather than the older cube artwork in its documentation repository. Redis is a registered trademark of Redis Ltd. or its affiliates. The [Redis trademark policy](https://redis.io/legal/trademark-policy/), updated September 15, 2026, permits truthful identification under its conditions and calls for attribution and registered-mark use. This directory supplies that attribution; it does not imply Redis endorsement. The official brand-guidelines redirect to `brand.redis.io` timed out during retrieval. The Redis / RQ queue remains a candidate.

Each downloaded SVG is kept byte-for-byte. The Redis asset is the exact original inline SVG element saved as UTF-8. No logo was redrawn, recolored, stretched or cropped. All image cells retain their original IDs; the historical `aws-icon-` prefix is an editable-reference identifier and does not describe the substituted artwork. Nine remaining icons continue to use the official AWS General/Category assets recorded in the adjacent AWS asset directory. All logos are embedded locally in Draw.io; no external image loading is required.

The 48px image boxes contain the original aspect ratios. Redis uses a 64px-wide image box in the existing icon space so its full wordmark remains recognizable. No component labels, card geometry, routes, relationships, notes or other pages are changed by this artwork substitution.
