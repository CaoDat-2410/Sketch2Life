## Frozen request rules for implementation

1. All Parent routes require verified Firebase adult identity, active Parent role, ownership checks, request IDs, bounded payloads, and no-store responses for child-linked data.
2. StoryRun and AI actions use `Idempotency-Key`; state-changing requests carry `expected_revision` and/or exact pinned hash. Stale requests return conflict and never silently rebase.
3. Lesson path binds the exact accessible published/shared lesson version/hash. Topic path carries the adult-confirmed topic and intended drawing subject as separate context values. A lesson pin and topic cards are not mixed unless the adult explicitly switches modes.
4. Drawing is mandatory before StoryRun creation and before VLM. A guide never receives profile, age, image, voice, or child identifiers.
5. Topic/object sets are curated-catalog-first and stable for the same draft; new set only on a newly started draft or explicit topic change. No AI call is made just to randomize cards. Custom input outside or ambiguously related to the topic blocks progression and is not silently rewritten.
6. VLM determines the depicted subject; the adult confirms/corrects it. Intended subject suggestions do not override image evidence. Topic/lesson mismatch permits correction or at most one retake.
7. Activity choices are canonical catalog references or explicitly labeled non-catalog drafts. A selected main activity snapshot must be persisted and read back before story generation. No selection, unknown write result, or stale revision blocks the story.
8. Story output must meet the Vietnamese 5–15 scene schema and generic educational/safety rules. No butterfly lifecycle requirement applies to other subjects. Video remains blocked until real quota admission is handed off.

- SVG catalog source/router is absent from this worktree despite a projected OpenAPI alias; locate the canonical catalog implementation or implement/mount the FEAT-063 SVG contract before enabling guide calls.
- Parent topic/object taxonomy and draft-set storage are absent.
- Activity suggestion route and selected-main-activity persistence are absent; current service alone is not an API.
- Generic story validation currently applies butterfly lifecycle rules to all subjects.
- FE Parent still routes through legacy guide and synchronous image/story requests; API errors must remain visible and truthful.
