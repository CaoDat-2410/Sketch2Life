# Image generation prompt briefs — Rev35

## Shared prompt baseline

All screens were generated with the built-in image-generation tool as one standalone screen per call. Use Vietnamese interface copy and the current product's role/layout. Parent screens are portrait Android, with the existing white, sky-blue, sunshine-yellow and mint palette and child-made drawing art. Teacher, Manager and Admin screens are 16:10 desktop web layouts based on current light-neutral/blue app surfaces. Keep examples fictional; avoid real child data. The generated asset is a visual concept, not a screenshot of a running app.

Age labels are illustrative for the 3–10-year-old scope. The exact age-band catalog remains versioned/open in the SRS and is not fixed by these mockups.

## P01 — Parent lesson library

Show the Parent lesson library with search, age/topic filters, illustrated cards and explicit Public/shared labels. Surface only lessons the Parent can currently access. Use Vietnamese labels such as “Thư viện bài học”, “Đã chia sẻ với gia đình”, “Công khai”.

## P02 — Parent lesson detail

Show the “Vòng đời bướm” topic, age band, estimated activity time, learning sequence, short drawing guidance, materials and an outdoor activity. Include the optional lesson script-direction switch and a “Dùng bài học” action. Do not include a Parent AI lesson-suggestion action.

## P03 — Parent drawing with optional line-sketch guide

Make the child's imperfect crayon drawing on paper the primary surface. Show a separate optional three-step monochrome butterfly guide, an explicit “Ẩn gợi ý” action and a “Chụp tranh” action. Never draw the guide over or replace the child's artwork.

## P04 — Parent capture and subject confirmation

Show the captured paper drawing and a tentative “Con bướm” subject recognition proposal. Require the adult to select “Đúng rồi” or “Chỉnh chủ thể” before continuing; keep image replacement available.

## P05 — Parent context and story review

Show only a minimal reviewed context snapshot, the adult's recorded/edited idea, a versioned three-scene storyboard and explicit “Xác nhận kịch bản” / “Chỉnh sửa” actions. Do not auto-approve.

## P06 — Parent video-generation progress

Show discrete stages for artwork receipt, subject confirmation, script review, scene generation and safety validation. Highlight only the current stage; avoid percentage, countdown and invented ETA. State that the video uses the drawing and already-confirmed information.

## P07 — Parent private video and activities

Show a private video inspired by the fictional child's crayon butterfly drawing, standard playback controls and the lesson-defined outdoor activity list below the player. Do not add social sharing, public gallery or media from another child.

## P08 — Parent history and feedback

Show recent delivered lessons and a school-scoped feedback thread with a Parent message, Teacher reply, text-only response input and “Gửi phản hồi”. Do not add general chat, media attachments or a completion toggle.

## T01 — Teacher lesson workspace

Show the Teacher's organization lesson workspace with search, age/status filters, lesson rows and visibility/status badges for Private, School, pending Public review and Public. Default Teacher content to School visibility.

## T02 — Teacher structured lesson authoring

Show structured fields for topic, target age, objectives, drawing steps, subject knowledge, activity materials/preparation/steps/safety, optional script direction and visibility defaulting to School. Include draft/preview actions. Do not invent an AI generation button.

## T03 — Teacher filtered document import and review

Show supported document upload, deterministic extraction, allowlisted structured fields with source-page references, correction controls and a missing-field warning. State that the original remains school-private and only filtered fields can reach AI after Teacher confirmation.

## T04 — Teacher session and optional Sketch Deck

Show an occurrence preparation surface with the opt-in Sketch Deck control enabled, a ready four-step generic butterfly line-art preview and presentation controls. Explain that disabling the option means no generation job; keep child profile data out of the Deck.

## M01 — School Manager publication review

Show a queue and version-specific Teacher lesson review, structured lesson content, safety checklist, transition from School to Public, feedback field and approve/return-for-revision actions. Do not expose child images or video.

## A01 — Platform Admin content moderation

Show a searchable public lesson catalog with owner/version/visibility/status, selected lesson metadata, provenance/version history and audit events, plus hide/reopen-public actions. Do not display child media or private child records.
