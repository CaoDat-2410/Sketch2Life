# UI02 — Motion notes

Role: Reusable UI component. Proposed interaction for a static mockup; no executable animation is included.

## Suggested behavior

Short bottom-sheet/dialog entrance. Busy state only after real request. Immediate state replacement under reduced motion.

## Accessibility

- Respect reduced-motion preferences; use immediate state replacement.
- Do not communicate state by color or motion alone.
- Do not fabricate loading progress, ETA, or success.
