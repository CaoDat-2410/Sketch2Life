# Motion and interaction proposal — Rev38 components

Static component references only; no executable animation is included.

## Shared rules

- Respect reduced-motion preferences.
- Use real server state for loading/success/failure; no fake progress/ETA.
- Keep focus and status labels readable; do not rely on color alone.
- Show revoke, publish, archive, retry and top-up actions only for valid states.

See each component group's MOTION.md for specific transitions: UI01–UI09.
