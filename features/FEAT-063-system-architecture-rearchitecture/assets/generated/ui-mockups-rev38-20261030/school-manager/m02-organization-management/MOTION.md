# M02 — Motion notes

Role: School Manager. Proposed interaction for a static mockup; no executable animation is included.

## Suggested behavior

Refresh summary/tables from organization data. Invite/add actions open focused dialogs.

## Accessibility

- Respect reduced-motion preferences; use immediate state replacement.
- Do not communicate state by color or motion alone.
- Do not fabricate loading progress, ETA, or success.
