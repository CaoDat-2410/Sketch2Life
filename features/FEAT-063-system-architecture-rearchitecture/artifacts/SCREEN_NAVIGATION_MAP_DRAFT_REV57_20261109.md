## 2. Navigation edges and recovery rules

- Parent path: P-01 → P-02 → P-03 → P-04 → P-05 → P-06 → P-07 → P-08 → P-09 → P-10 → P-11. A preset may be pinned at setup; no outdoor activity is chosen before video. No-preset query/no-query is owner decision Q-13.
- Teacher path: T-01 → T-02 → T-03 → T-04 → T-05 → T-06 → T-07 → T-08 → T-09 → T-10. T-07 shows exactly the server-selected child. No navigation edge offers a free-form child picker.
- School Manager path: SM-01 → SM-02/SM-03/SM-04/SM-05. Force-close screen/action is not added; only BR-41 command exists and resolver details remain Q-13.
- Platform Admin path: PA-01 → PA-02. No child profile/media navigation exists for Platform Admin or tenant manager by role alone.
- Back navigates to the prior permitted review screen and reloads current server revision. Cancel is a server command when it changes a run; local dismissal alone must not imply cancellation. Resume always reloads state, owner scope and exact revision/hash.
- Every screen must include loading, empty, denied, stale/conflict and recoverable error states appropriate to its command. Error copy/status mapping must reuse the approved API contract, not add UI-only permission.
