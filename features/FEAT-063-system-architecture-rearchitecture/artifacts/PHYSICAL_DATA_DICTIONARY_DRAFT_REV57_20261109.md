## 2. Retained/refactored migration crosswalk gate

DTR §§3–4.1 records source columns and target operation notes. A complete approved migration still needs a column-by-column disposition (keep/rename/split/derive/retire), type conversion, null/default transition, FK/index change, preserved-ID/history rule, dependency order, validation query, expected reconciliation tolerance, rollback point and owner approval. DTR §4.1 is not a migration script and does not prove database state.

| Required gate | Current status |
|---|---|
| Source/target column disposition for every retained mapping | PARTIAL: source fields/operation notes linked where table names match; exact mapping and transform incomplete |
| Backfill order/dependency and preserved history | OPEN-TECHNICAL |
| Data-quality query, expected row/hash reconciliation and validation result | OPEN-TECHNICAL; none run in Rev57 |
| Rollback/restore point and irreversibility review | OPEN-TECHNICAL |
| Approved target DDL and schema version | BLOCKED |
| Production/local as-built parity | BLOCKED; no live DB evidence checked |

## 3. Required physical declaration fields

Owner-approved DDL must identify schema.table.column, SQL type, NULL, DEFAULT, PK, same-owner FK and delete/update action, UNIQUE/CHECK, composite/partial indexes with predicates, owner, sensitivity/PII, lifecycle and source/target status. Cross-owner links use typed opaque references and application contracts; no cross-owner SQL FK. Active grant uniqueness, one successful sample per occurrence, idempotency receipts, exact version/hash fences, quota receipts and outbox reconciliation need explicit approved constraints/mechanisms.

## 4. Evidence boundary

The source-path column records the repository declaration referenced by the Data Table Register and whether that path exists at the selected commit. It does not claim every target mapping is deployed or every migration was applied. No DDL, database query or migration ran. Physical ERD remains BLOCKED until approved dictionary/DDL, constraints, migration mapping and environment-specific as-built proof are supplied.
