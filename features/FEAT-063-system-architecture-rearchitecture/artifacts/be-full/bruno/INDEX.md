### Run order and prerequisites

- **Run order after the renumber**: the dependent requests were written in number order. Requests 400-438 (the former 170-208) create the values that many later requests read: 400 (StoryRun and context values for 252-254 and 289-291), 412 (`created_class_id` and ETag for 256, 296, 297, 317-325, 340-352) and 438 (`generic_upload_id` for 215-223 and 258). Run 400-438 first, or set those variables by hand; a plain run in number order starts them too late.

- **500–507**: Run on a fresh approved-plan occurrence. Run 504 before 506 (506 advances the selection ETag to `"2"`), and run 507 after 506.
- **508–512**: Run next using the confirmed selection from 506. Run 509 after 508 while the Teacher lock is held; 511 uses a Parent bearer token and does not overwrite `teacher_run_id`; 512 runs with a Parent bearer token after 508.
- **513–518 (and 519)**: Need completed uploads (`teacher_asset_ref`), a confirmed run context (for 515), a voice idea (for 516–517, with 517 after 516), and a seeded first story at `SCRIPT_REVIEW` with confirmed subject (for 518). Request 519 uses a non-responsible Teacher bearer token.
- **520–524**: Need a run with a confirmed script (520–522) and a finished video worker so the run is at `VIDEO_READY` (523–524).
- **525 and 526**: Each needs its own run at `VIDEO_READY` because 525 returns its run to `SCRIPT_REVIEW` while 526 moves its run to `COMPLETED`.
- **527**: Needs a fresh confirmed selection (repeat 500 and 506) on the same occurrence after 526.
- **528**: Uses its own dedicated active run (`cancel_run_id`, `cancel_run_revision`) so it does not terminate the run used by 508–527.
- **529**: Run before 526 on the same `VIDEO_READY` run, after refreshing `occurrence_etag` via a GET of the occurrence.
- **530**: Run after 526 (uses `completed_run_id` and `completed_generation_id`, with `occurrence_etag` refreshed via a GET of the occurrence).
- **531 and 532**: Run after 529 (532 uses `projection_token` from 531).
- **533**: Uses a Parent bearer token against `occurrence_id`.
- **534**: Manual and clock-dependent; copy the token from 531 into `expired_projection_token` and run more than 300 seconds later (skip otherwise).
