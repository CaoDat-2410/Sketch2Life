# FEAT-014 known limitations

- This is a local text console, not Android UI, backend API, Gate B, or production runtime.
- It evaluates one activity selected by the operator; it does not search, rank, recommend, personalize, or map observations.
- Inputs are synthetic closed-schema IDs and numbers. The tool is intentionally unsuitable for real child narratives, media, diagnoses, or free-form observations.
- `VALID_CANDIDATE` proves only deterministic fixture eligibility for the supplied input; it does not prove learning outcome, individual suitability, or Montessori quality.
- Golden records remain provisionally owner reviewed and `production_eligible=false`; qualified Montessori review remains required.
- Evidence recording is local and opt-in. There is no telemetry, account, database, or shared run store.
