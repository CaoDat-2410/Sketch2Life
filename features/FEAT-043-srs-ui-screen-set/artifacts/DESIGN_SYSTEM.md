- Current mobile tokens: sky#38BDF8, primary#2563EB, yellow#FBBF24, mint#34D399, coral#FB7185, off-white#F8FAFC, heading#0F172A, body#334155, lines#E2E8F0. White cards, rounded16–30px, gentle restrained shadows, rounded sans-serif Vietnamese typography.
- Child: landscape Android tablet4:3, edge-to-edge screen, generous icon+short-label touch controls, canvas dominant, no desktop sidebar. C03 basic young-child set; C03b9–12 advanced proposal, teacher-enabled tools documented as unadopted refinement.
- Teacher/Admin: desktop16:10 full app viewport, persistent compact left sidebar and header/breadcrumb/school/class context, dense but readable functional workspace. No device frame, multi-screen collage or marketing poster.
- Teacher nav: Tong quan/Lop hoc/Phien hoc/Duyet AI/Thu vien/Ho so hoc tap/Cai dat, rendered with correct Vietnamese diacritics. Admin nav maps A01–A10 consistently.

- Teacher approves each Sketch; stale/unsafe proposals cannot publish; generating video has no skip/fallback or invented percentage; exhausted failure exposes Teacher retry/skip/end. Child sees only approved artifacts and keeps its own art/agency.
- Shared tablet names active contributor and turn. Accepted checkpoint versus unsent draft is explicit; do not show false saved success. Off-screen activity includes materials/safety/Teacher preparation. Assessment separates child response, direct evidence, Teacher observation and AI draft, with not-observed option.

- Main34 screens plus9 essential variants are design coverage, not exhaustive state screenshots or proof of authorization/accessibility/native behavior. Every image remains REVIEW_PENDING; no promotion to approved/applied or runtime reference.
