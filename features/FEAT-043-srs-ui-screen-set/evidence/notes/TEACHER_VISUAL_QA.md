## Targeted revisions and provenance

T03 and T12 each needed one targeted built-in image edit. Initial prompts are preserved as `assets/prompts/T03-first-attempt.txt` and `assets/prompts/T12-first-attempt.txt`; the exact final edit prompts are the corresponding ID prompt files. Initial PNGs are preserved unchanged under `assets/generated/attempts/` only to prove the edit inputs and are not final screen-set/gallery selections. Final manifests contain `generation_history`, actual edit-target paths and SHA-256 hashes. All remaining derivative screens record T05 as the actual style reference with its relative PNG path, role and hash; T05 records no input image because it was generated from text.

All selected image hashes, input hashes and final prompt hashes were checked. The final selected 13 images and their manifests are complete, with **REVIEW_PENDING** visual status. No assets were promoted to `approved` or `applied`, and no runtime code, package, Git commit or push was performed by this workstream.

## Limits

Static mockups cover the main Teacher workspace responsibilities; they do not exhaust loading/empty/stale/conflict/access-revoked states, confirm native behavior, establish authorization/accessibility, or adopt a Teacher web framework. Vietnamese text was visually inspected but generated UI copy remains subject to human design review. Domain actions must revalidate scope, purpose, version and exact content in implementation. No real child data, guardian documents, service credentials or provider endpoints were included.
