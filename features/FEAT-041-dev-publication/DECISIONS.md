# Feature decisions

- D01: direct owner request authorizes branch push/dev integration; no repeated approval flow.
- D02: default scope is reviewed documentation with existing committed history; leave eight uncommitted historical under-nine runtime paths byte-identical. New target implementation is not implied by publishing target SRS.
- D03: exclude untracked local temporary/rendered/form/capture binaries without deleting or removing tracked history. Normalize source-machine prose using owner-local attachment names, preserve original source SHA/version/authority and ignored local prose backup/hash manifest.
- D04: add missing evidence placeholders, without inventing actual test outputs. Stage exact safe paths after security/architecture/harness/document checks.
- D05: keep workspace on source branch; dev integration is a verified fast-forward when possible. Never force, reset or discard local work. Preserve remote history and verify resulting SHAs.
- D06: Git normalization would alter archived source/task hashes. Narrow gitattributes keeps their exact bytes; normal prose newline correction retains meaning and local original backup. Staged index SHA checks verify preservation before commit.
