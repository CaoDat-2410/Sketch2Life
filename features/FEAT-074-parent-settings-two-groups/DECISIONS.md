# FEAT-074 decisions

## D-074-01 — Use two top-level settings groups

Keep parent identity and app preferences in “Tài khoản & cài đặt”. Put privacy/AI-data information, profile-access information, and password change together under “Bảo mật”. This balances the existing destinations by user intent and keeps all current settings accessible.

## D-074-02 — Preserve existing setting behavior

Change navigation grouping and labels only. Keep current values, validation, feedback, preview-only behavior, and account/privacy content intact. Do not add an API or persistence behavior.
