# Sketch2Life Mobile Design System & Component Library

## Architecture
- `src/theme.ts`: Primary color palette, typography tokens, radius and elevation shadows.
- `src/components/cards/`: 12 reusable presentation cards following Montessori visual guidelines.
- `src/screens/modules/`: 24 decoupled screen containers covering full 8-step child and parent workflow.

## Guidelines
- Maximum digital interaction: under 10 minutes per session.
- Tactile 3D button feedback with Kid3DButton component.
- Strict child-safe copy compliance with zero technical leakage.
