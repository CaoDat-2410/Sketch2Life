# Sketch2Life — Giao diện Quản trị nền tảng (Platform Admin UI)

Thư mục độc lập chứa toàn bộ mã nguồn giao diện cho vai trò **platform-admin-ui** trong dự án **Sketch2Life**.

## Danh sách màn hình
- A01 (`/a01-content-moderation`): Kiểm duyệt thư viện bài học công khai & ẩn bài học kèm lý do bắt buộc (UI03)
- A02 (`/a02-platform-operations`): Vận hành nền tảng (Tổ chức, Danh mục hoạt động, Chính sách & Nhật ký kiểm duyệt)

## Cài đặt & Chạy độc lập
```bash
npm install
npm run dev
```
- Ứng dụng chạy mặc định tại: `http://localhost:5174`

## Kiểm tra TypeScript & Build Production
```bash
npm run build
```
