# Sketch2Life Kids (apps/child-ui)

Landscape-oriented Montessori child drawing experience built with Expo and React Native.

## Features
- **Montessori Touch Canvas**: Tactile drawing surface with pen, eraser, size picker, and natural palette.
- **Peer Collaboration Garden**: Turn-taking collaborative canvas allowing children to build shared ecosystems.
- **Gate A / B Review Status**: Gentle child-friendly status tracking for teacher approvals.
- **Botanical Storyline**: 3-step nature discovery cards (seedling, photosynthesis, bloom).
- **Physical Screen-Off Transition**: Hands-on Montessori leaf collage and outdoor nature activities.
- **Emotional Reflection**: Post-session child feeling survey without performance pressure.
- **Resilient Offline Reconnect**: Local stroke caching and seamless recovery on Wi-Fi interruptions.

## Target Environment
- **Device Orientation**: Fixed Landscape (16:9 / 16:10 tablets)
- **Framework**: Expo Router (Expo SDK 55), React Native 0.83, React 19
- **Touch Target Standard**: Minimum 64x64px hit targets with large rounded corners and high contrast.
