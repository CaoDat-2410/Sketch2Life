# Child UI Architecture Overview

## Design Principles
1. **Zero Text Dependency**: Visual symbols, audio cues, and large iconography.
2. **Tactile Simplicity**: Touch targets at least 64x64px with responsive press feedback.
3. **Low-Stimulation Harmony**: Soft Montessori pastels instead of hyper-stimulating saturated neon tones.
4. **Resilient Local Persistence**: Auto-save all drawing strokes locally before transmitting over the network.
