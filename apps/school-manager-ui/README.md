# Sketch2Life — Giao diện Quản lý trường (School Manager UI)

Thư mục độc lập chứa toàn bộ mã nguồn giao diện cho vai trò **school-manager-ui** trong dự án **Sketch2Life**.

## Danh sách màn hình
- M01 (`/m01-publication-review`): Duyệt công khai giáo án với 4 mục kiểm tra bắt buộc (UI03)
- M02 (`/m02-organization-management`): Quản lý trường, lớp học, slot lớp, giáo viên, quota & bảng chia sẻ UI08

## Cài đặt & Chạy độc lập
```bash
npm install
npm run dev
```
- Ứng dụng chạy mặc định tại: `http://localhost:5173`

## Kiểm tra TypeScript & Build Production
```bash
npm run build
```
